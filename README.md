# My App - Starter Project

Aplikasi web modern yang dibangun menggunakan **React 19**, **Vite**, **Tailwind CSS v4**, dan **React Router v8**.

---

## 🚀 Cara Instalasi & Menjalankan Proyek

Ikuti langkah-langkah berikut untuk menjalankan proyek di komputer lokal Anda:

### 1. Clone Repository & Masuk ke Direktori
```bash
git clone <URL_REPOSITORY_ANDA>
cd my-app
```

### 2. Install Dependencies
Jalankan perintah berikut untuk menginstall seluruh paket yang dibutuhkan:
```bash
npm install
```

### 3. Jalankan Server Pengembangan (Development)
```bash
npm run dev
```
Buka browser dan akses alamat yang tertera pada terminal (biasanya `http://localhost:5173`).

---


## 📦 Tech Stack & Packages Utama

Proyek ini telah dilengkapi dengan library dan tools berikut:

- **Core & Routing:**
  - `react` & `react-dom` (v19) - Library UI utama.
  - `react-router` (v8) - Manajemen routing / navigasi halaman.
  - `vite` - Tooling frontend ultra-cepat.
- **State Management:**
  - `zustand` - Manajemen state global yang ringan dan fleksibel.
- **Styling & UI Components:**
  - `tailwindcss` (v4) - Framework CSS utility-first.
  - `shadcn` & `radix-ui` - Komponen UI yang dapat diakses dan di-custom.
  - `class-variance-authority` & `cn` - Helper untuk manipulasi class/styling dinamis.
  - `lucide-react` - Set ikon modern.
  - `@fontsource-variable/inter` - Font Inter terintegrasi.
  - `tw-animate-css` - Ekstensi animasi Tailwind.
